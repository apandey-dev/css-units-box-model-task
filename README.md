## 1. Project Title
**CSS Units, Box Model and Responsive Viewport Alignment**

## 2. Assignment Objective
To demonstrate precision layout design using CSS Viewport Units (`vw`, `vh`) and the CSS Box Model (`box-sizing: border-box`) without relying on Flexbox, CSS Grid, `overflow: hidden`, or absolute/relative positioning.

## 3. Technologies Used
- **HTML5** (Clean semantic markup)
- **CSS3** (Viewport units, gradients, box-model properties)

## 4. Features Implemented
- **Viewport Dimension Sizing:** The container maintains exactly 25% viewport spacing from both left and right edges (`width: 50vw; margin: 10vh 25vw;`).
- **Strict Box Model:** Universal `box-sizing: border-box` eliminates unintended overflow.
- **Normal Flow Architecture:** Built purely with standard block formatting context (no Flexbox, no `overflow: hidden`, no `position: relative/absolute`).
- **Gradient Button:** Full-width interactive button styled with a vibrant linear gradient from warm amber `#fbb913` to lush green `#4dcf41`.
- **Responsive & No Unwanted Scrolling:** Clean viewport adaptation without horizontal scrollbars.
